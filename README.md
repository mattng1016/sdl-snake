# SDL Snake

Classic Snake game built using C and SDL

## Requirements

- CMake 3.20+
- SDL3 
- C Compliler (gcc)

### MacOS setup 

- Homebrew
```bash
```bash 
brew install sdl3 
```
```
```


## Build 
```bash 
```bash 
mkdir build 
cd build 
cmake .. 
cmake ..--build . 
```


## Run 
```bash 
./snake*
